# Kassi Tap

## How do I install these formulae?

`brew install kassi/tap/<formula>`

Or `brew tap kassi/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kassi/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
